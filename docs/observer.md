# Xray 观察面板

运行监控已作为工作区的「运行概览」首页，地址 `/overview`，旧 `/observe` 自动跳转。统一使用 DefaultLayout、鲸栈顶栏、主导航、面包屑、页签和主题切换。登录后直接进入工作台，没有单独的 Xray 连接页。采用 Vue 3 Composition API、TypeScript，复用 AppTable（列设置、复制、分页）与 AppChart，接口基线为 v1.0.1。

## 启动与连接

开发服务运行 `pnpm dev`。普通开发模式将 `/api/auth` 与 `/api/v1` 转发到同一个后端；mock 模式的 `/api/auth` 仍使用本地演示登录。默认联调地址为 `http://172.21.185.75:18080`。WSL IP 变化时，在被 Git 忽略的 `.env.local` 设置 `XRAY_API_TARGET=http://新的地址:18080`，再重启 Vite。不要配置 `VITE_` 令牌变量，也不要把令牌写入环境文件或构建产物。

生产运行 `pnpm build`，由后端同源托管 `dist/`。当前后端直接读取该目录，重新构建后刷新 `/overview` 即可，不需要重启后端。其他部署需将页面路径回退到 `index.html`，`/api/*` 应保留 JSON 错误响应。

首次访问未初始化的服务时，统一登录页读取 `/api/auth/setup-status` 并显示创建独立工作区账号的表单。用户填写用户名、密码、确认密码，以及仅本次使用的初始化校验码（部署端配置的初始化凭据）。`GET /api/auth/csrf` 后通过 `POST /api/auth/setup` 创建账号，后端保存 bcrypt 账号文件并签发 HttpOnly 会话 Cookie。初始化校验码不存储、不写入 URL 或构建产物。已有账号后该初始化端点不可再次创建用户。

后续登录统一使用 `/api/auth/login`（用户名/密码），不使用 3x-ui 账号。浏览器通过同源 Cookie 访问业务 API 和 SSE，无需输入或持有 Xray Bearer。会话当前为 8 小时绝对有效期，刷新、切换菜单、关闭页签后恢复仍可直接进入；退出或会话失效后才回到统一登录。脚本仍可使用后端原有 Bearer 认证。

`/overview` 与所有业务页使用同一套路由守卫、auth Store 和权限目录，要求 `observe:read`，无观察页特例。原设备/系统功能仍按实际服务端权限显示，后端没有提供的业务不假装可用。离开监控页会取消其请求和流，Cookie 会话本身不受影响。401 会使统一会话失效并跳转登录。

内容区取消最大宽度限制并铺满工作区。大屏中主机指标与资源并排，日志全宽；中小屏自动堆叠，表格在自身区域滚动。

## 页面行为

- 概览和节点列表每 30 秒刷新；可切换节点，节点在线与 Xray 运行状态分别呈现。`null` 内核状态显示「未探测」，未获知的状态、版本和计数不伪装为零或停止。
- 「近 5 分钟活跃客户端」统计有 accepted 事件的客户端，按节点内去重后求和，不代表并发连接数；标题悬停可查看口径。
- 主机指标按 UTC 毫秒对齐到完整分钟桶，可查最近 1/6/24 小时，每分钟刷新。CPU、内存、磁盘与网络使用真实返回值，零与缺失分开显示；缺采样的点保持断开。主机网络含容器网卡，不能解释为代理流量。
- 入站和客户端每分钟刷新，默认按 20 条独立分页，可通过 AppTable 改变每页条数；可展开客户端最近一小时的速率曲线。累计字节用 BigInt 格式化，配额 `"0"` 和 `null` 分开显示。跨 epoch 桶依后端返回的 null 留空，前端不跨 epoch 计算增量。
- 页面隐藏时停止轮询和 SSE，恢复后重新拉取。切换节点会销毁旧节点下的请求、图表和流，避免旧结果覆盖新节点。

## 日志与恢复

实时模式使用 fetch + 同源 Cookie SSE，不用原生 EventSource。只请求 log 事件（服务端仍发送 ping），游标作为不透明字符串完整透传。断线后退避重连，429 遵守 Retry-After。409 或非法旧游标时清空游标、创建新连接，并用固定快照补查最近一小时最新 300 条；重放和 REST 补查按 `(node_id, log_id)` 去重。

实时视图最多保留 300 条，以观测时间降序、接收时间降序和日志 ID 字节序排序；它不是全部日志导出或无损持久存储。更多记录使用历史查询。历史模式暂停实时流，支持 1/6/24 小时窗口、动作与关键字过滤，首次响应的 `from_ms/to_ms/as_of_ms` 固定用于翻页，重新查询才刷新快照。翻页最多 10 万条，超出提示缩小范围。

实时补查遇到 429 时，等待 Retry-After 后自动重试，不依赖 SSE 再次断开。暂停实时、切换模式/节点、隐藏页面或离开时取消待执行补查。实时空态提供「查历史」入口；客户端名称悬停显示完整 ID；日志行支持点击或键盘按钮展开纯文本详情。重新查询、筛选或翻页会收起详情，实时更新则保留仍在列表中的展开项。

采集器刚启动时，过去一小时通常只有部分覆盖。页面直接展示 `coverage.partial`、原因和实际可用范围；空结果显示「暂无采集记录」，不推断查询时间窗内从未发生事件。日志内容通过 Vue 文本插值渲染，显示时间使用浏览器本地时区，无手工 +8 小时。

## 检查

```sh
pnpm format:check
pnpm lint
pnpm test
pnpm build
pnpm exec playwright test tests/e2e/observe.spec.ts
```

浏览器回归通过拦截 API 验证统一登录、首次初始化、Cookie 恢复、401 清理、null/零值、大字节计数、历史快照、SSE 游标恢复去重、限流和移动布局，不修改真实后端数据。真实 smoke 用例默认跳过；明确设置进程环境变量 `OBSERVER_TEST_USERNAME`、`OBSERVER_TEST_PASSWORD` 后运行同一测试文件即可测试统一登录。设置 `OBSERVER_LIVE_URL` 可指定同源托管地址，测试使用专用临时账号及实例，登录、查询、刷新、退出，不在正式实例创建测试账号。请勿将密码或初始化校验码提交到仓库。

目前没有告警配置、写入 3x-ui 或管理节点配置的功能。`data_mode=live` 表示数据来源，覆盖和探测质量仍以各字段为准。
