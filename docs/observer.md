# Xray 观察面板

入口 `/observe`，已接入原项目的 DefaultLayout、鲸栈顶栏、主导航、面包屑、页签和主题切换。侧栏「Xray 观察面板」和原登录页均可进入。采用 Vue 3 Composition API、TypeScript，复用 AppTable（列设置、复制、分页）与 AppChart，接口基线为 v1.0.1。

## 启动与连接

开发服务运行 `pnpm dev`。Vite 仅将 `/api/v1` 转发到观察后端，默认联调地址为 `http://172.21.185.75:18080`。WSL IP 变化时，在被 Git 忽略的 `.env.local` 设置 `XRAY_API_TARGET=http://新的地址:18080`，再重启 Vite。不要配置 `VITE_` 令牌变量，也不要把令牌写入环境文件或构建产物。

生产运行 `pnpm build`，由后端同源托管 `dist/`。当前后端直接读取该目录，重新构建后刷新 `/observe` 即可，不需要重启后端。其他部署需将页面路径回退到 `index.html`，`/api/*` 应保留 JSON 错误响应。

用户手动输入令牌，前端调用 `/api/v1/auth/session` 核对版本和 `observe:read` 权限。令牌仅保留在页面内存；刷新、离开观察页或断开后释放，不写入 URL、localStorage、sessionStorage 或 Cookie。任何请求返回 401 时清除观察会话、停止轮询和流连接，返回令牌入口。

原设备、系统管理和演示登录仍使用原来的 Cookie 接口；观察后端不提供这些接口。`/observe` 是现有布局的子路由，使用显式 `authentication: 'observer'` 元数据；仅该页跳过 Cookie 会话检查，数据请求仍须通过观察后端的 Bearer 授权。它没有被标记为 public，也不会给原设备、系统等页面放开权限。未登录后台时，工作区只显示观察功能与后台登录入口；已登录时保留原有权限菜单及账户。

观察页参与原页签系统。为确保离开后停止所有请求并释放令牌，当前设为 `keepAlive: false`；切换到其他页、关闭或刷新该页签后需重新连接观察服务。其他业务页面的缓存策略保持原样。

## 页面行为

- 概览和节点列表每 30 秒刷新；可切换节点，节点在线与 Xray 运行状态分别呈现。`null` 内核状态显示「未探测」，未获知的状态、版本和计数不伪装为零或停止。
- 主机指标按 UTC 毫秒对齐到完整分钟桶，可查最近 1/6/24 小时，每分钟刷新。CPU、内存、磁盘与网络使用真实返回值，零与缺失分开显示；缺采样的点保持断开。主机网络含容器网卡，不能解释为代理流量。
- 入站和客户端每分钟刷新，默认按 20 条独立分页，可通过 AppTable 改变每页条数；可展开客户端最近一小时的速率曲线。累计字节用 BigInt 格式化，配额 `"0"` 和 `null` 分开显示。跨 epoch 桶依后端返回的 null 留空，前端不跨 epoch 计算增量。
- 页面隐藏时停止轮询和 SSE，恢复后重新拉取。切换节点会销毁旧节点下的请求、图表和流，避免旧结果覆盖新节点。

## 日志与恢复

实时模式使用 fetch + Bearer SSE，不用原生 EventSource。只请求 log 事件（服务端仍发送 ping），游标作为不透明字符串完整透传。断线后退避重连，429 遵守 Retry-After。409 或非法旧游标时清空游标、创建新连接，并用固定快照补查最近一小时最新 300 条；重放和 REST 补查按 `(node_id, log_id)` 去重。

实时视图最多保留 300 条，以观测时间降序、接收时间降序和日志 ID 字节序排序；它不是全部日志导出或无损持久存储。更多记录使用历史查询。历史模式暂停实时流，支持 1/6/24 小时窗口、动作与关键字过滤，首次响应的 `from_ms/to_ms/as_of_ms` 固定用于翻页，重新查询才刷新快照。翻页最多 10 万条，超出提示缩小范围。

采集器刚启动时，过去一小时通常只有部分覆盖。页面直接展示 `coverage.partial`、原因和实际可用范围；空结果显示「暂无采集记录」，不推断查询时间窗内从未发生事件。日志内容通过 Vue 文本插值渲染，显示时间使用浏览器本地时区，无手工 +8 小时。

## 检查

```sh
pnpm format:check
pnpm lint
pnpm test
pnpm build
pnpm exec playwright test tests/e2e/observe.spec.ts
```

浏览器回归通过拦截 API 验证独立鉴权、401 清理、null/零值、大字节计数、历史快照、SSE 游标恢复去重、限流和移动布局，不修改真实后端数据。真实 smoke 用例默认跳过；明确设置进程环境变量 `OBSERVER_TEST_TOKEN` 后运行同一测试文件即可通过开发代理测试。设置 `OBSERVER_LIVE_URL` 可指定同源托管地址，测试只执行只读 API 请求。请勿将测试令牌提交到仓库。

目前没有告警配置、写入 3x-ui 或管理节点配置的功能。`data_mode=live` 表示数据来源，覆盖和探测质量仍以各字段为准。
