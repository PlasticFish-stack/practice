# 多页签与页面缓存

内容区顶部展示已打开页面，可切换、关闭，支持「刷新当前」「关闭其他」「关闭右侧」「关闭全部」。关闭活动页后优先进入左侧相邻页，没有相邻页时进入当前用户的默认首页。

- 同一路径的 query/hash 变化复用一个页签，保存最后一次访问地址；例如个人中心查看与 `?edit=1` 共享一个页签。不同参数路径分别缓存。
- 普通页面默认使用 KeepAlive 保留组件状态。列表切回来保留筛选、分页，重新请求最新数据；个人资料编辑草稿保留。页面滚动位置也按页签记录。
- 每个页签独立持有 `max=1` 的 KeepAlive，关闭页签会卸载其缓存容器并释放实例；刷新当前只替换该页实例，不清空其他页面。
- 最多保留 15 个页签，超过后移除最久未访问项。缓存只在当前运行的工作空间中存在，不写入浏览器存储；整页刷新后重新建立。
- 退出、切换账号、离开后台布局会清空页签。会话权限变化时，移除无权访问的页签及其实例，隐藏菜单本身不撤销已有页面的访问权限。
- 窄屏页签栏横向滚动，切换页面、改变窗口宽度时自动露出当前页签。支持方向键、Home/End 切换，以及 Delete 关闭当前页签。

路由可配置：

```ts
meta: {
  title: '页面名称',
  tab: true,       // 默认创建页签，false 可用于错误页等临时页面
  keepAlive: true // 默认缓存，false 时切换离开后销毁页面
}
```

缓存后的页面只会触发 onDeactivated，不会在普通切换时卸载。列表离开时取消未完成请求，返回后恢复查询；表格的全局拖选监听在停用时解绑，临时编辑弹窗和列设置浮层关闭。WebSocket 演示离开时暂停连接，保留消息输入和已接收内容，回来后可手动连接。

职责：`stores/pageTabs.ts` 管理页签、实例编号与容量；`layouts/usePageTabs.ts` 协调导航、权限、关闭及滚动；`AppPageTabs.vue` 负责交互；`AppPageView.vue` 持有实际缓存容器。
