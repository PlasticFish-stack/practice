# Google Material Symbols

Local SVG paths downloaded from Google's official `fonts.gstatic.com/s/i/short-term/release/materialsymbolsoutlined/{name}/wght500/24px.svg` endpoints.

Style: Material Symbols Outlined, 24px, weight 500. Copyright Google LLC. Licensed under Apache-2.0; see LICENSE, copied from [google/material-design-icons](https://github.com/google/material-design-icons), commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`.

Regenerate with `node scripts/sync-material-icons.mjs`, then format the generated TypeScript with the project Prettier configuration. No remote fonts or runtime requests are required.

The export names preserve existing menu identifiers and Element Plus icon contracts. Vite aliases Element Plus icon imports to this module so built-in controls use the same icon family. Add mappings here when upgrading Element Plus if a new icon export is required.
